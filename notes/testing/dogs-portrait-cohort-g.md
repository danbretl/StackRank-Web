## Lessons to carry forward

- Compare proposed identities with published canonical names, aliases and registry standards before
  acquiring references or generating. Distinct catalog IDs alone do not prove distinct breed identities.
  Legitimate color/size varieties remain eligible, but duplicate synonyms do not count as new coverage.
- Exact source descriptions matter more than filenames or search results. Visually inspect the original,
  preserve the File revision and original chain, and resolve public-domain policy metadata before a call.
- Distinguish natural bobtails and standard-permitted short tails from cropped framing. Correct a tail
  that violates the specific breed standard; do not regenerate a good native for speculative concerns.
- Prompt file bytes and submitted prompt text can differ by a final newline. Hash the actual submitted
  string, store the file hash separately, and preserve correction evidence instead of rewriting history.
- Shared morphology references need identity-specific asset namespaces when a legitimate variety uses
  the same source bytes as a published parent. Do not overwrite existing rights rows.
- Separate source/profile/native acceptance from integration and publication. A good image can still
  be held for duplicate identity or unresolved rights; it never counts toward completed distinct pairs.
