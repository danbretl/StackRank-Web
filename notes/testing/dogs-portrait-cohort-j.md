- First five pairs passed source, prose, image and independent peer review. Specify rich mahogany tan throughout the first prompt for this exact variety.
- Inspect the exact selected path from the packet. Rejected candidate 1 images can coexist with selected candidate 2/3 images; filenames guessed from an ID are unsafe.
- A strong entire dog within a native 3:2 master is not regenerated merely for a nominal subject-height target. Larger accepted hounds retain real top/bottom/tail margins and coherent paws. All delivery variants preserve the native framing.
- A reference provides morphology and coat only. Pose, light and scene must change, with source handlers, show leads, fences and branding removed. A short handler contact on a reference tail can be acceptable when complete morphology remains readable; a hidden or clipped tail cannot.
- Exact identity precedes image spending. Landseer Newfoundland `0200811` is an alias of frozen white-and-black Newfoundland primary `0200941`; preserve its excellent source packet for the correct primary, but do not count both. American strain labels, designer crosses and historical names need independent population evidence, not plausible parent morphology.
- The 2026 PLOS Cockapoo/Labradoodle owner-survey paper supports scoped reports of excitability/separation behavior. It does not predict an individual dog or establish behavior for a distinct multigenerational Australian Labradoodle program.
- Country-specific CC BY-SA 3.0 Luxembourg and 2.0 Germany licenses are added only for private morphology references after official deed review. Existing licenses, source rules and purpose gates remain unchanged; validators deny every photo-delivery purpose for these additions.
- Built-in output bytes are retained unchanged at 1536×1024, along with every rejected attempt, exact pre-call prompt, original path/hash and actual agent assignment. Builder reuse is limited to unchanged approved masters and existing byte/hash/role/dimension-matched variants; a new master always requires encoding.
- Full and authored short descriptions are reviewed independently of their writer. Read actual primary text, including the relevant paragraph outside automated keyword windows. History-only notes are appropriate when character evidence is thin; limitations stay in source notes.

- Frozen groups describe preparation, while explicit release membership allows approximately 25 excellent completed pairs to ship without blocking on source holds in an earlier preparation group. J01 contains 28 accepted pairs.
- Compiled full and short prose must both match independent approval hashes. Supplemental source chains must be linked explicitly for archiving; a pinned File page alone does not preserve an unlinked original Flickr or earliest-revision receipt.
- Complete compilation before browser/preservation checks: launching dependent checks against the older manifest causes avoidable failures.
